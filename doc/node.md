# NodeJs
[NODE] (https://nodejs.org/en) es un entorno de ejecucion Javascript multi plataforma de codigo abierto y gratuito

Dentro de los frameworks para crear servidores web para node tenemos 
 - Fatify
 - AdonisJs 
 - NestJs
 -Koa
 - Expressjs


# ExpressJs

flecible no impositivo tanto en el flujo de
